## 旅のプロフィール

| | |
|---|---|
| 👨‍👩‍👧 **メンバー** | 大人 2名（30代）／ 子供 1名（2歳半） |
| 📅 **期間** | GW2026 ・ 2泊3日 |
| 🚗 **移動** | マイカー |
| 🏨 **宿泊** | 鳥羽国際ホテル（高台立地・標高約20〜30m） |
| 🎯 **テーマ** | 水族館で子供が大興奮 ＋ 伊勢の文化と海鮮 |
| 🌊 **津波安全性** | ◯ 高台立地のため相対的にリスク低（事前確認推奨） |

---

> ### ✅ このプランがおすすめな方
> - 子供に水族館を見せたい
> - 伊勢神宮・おかげ横丁の文化体験も外せない
> - 海鮮（伊勢海老・牡蠣）をしっかり食べたい
> - ホテルは高台で津波リスクを抑えたい

# 🗓️ 1日目｜移動 → 鳥羽水族館 → チェックイン

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  目的地まで高速移動 ＋ 水族館でテンションMAX
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

| 時間 | 場所・行動 | メモ |
|:---:|---|---|
| **06:30** | 🏠 自宅出発 | GW渋滞を避けるため早朝出発が鉄則 |
| **10:00** | 🅿️ 鳥羽市内・休憩 | コンビニで軽食・おむつ替え |
| **10:30** | 🐟 **鳥羽水族館 入館** | 事前オンラインチケット購入必須 |
| **13:00** | 🦐 昼食：港近くの海鮮食堂 | 伊勢海老汁定食・海鮮丼。子供用おにぎり持参 |
| **14:00** | 🏨 ホテルへ移動（車で5〜10分） | |
| **14:30** | ✅ チェックイン | 和室 or 高台側客室をリクエスト |
| **15:00** | 💤 **子供 昼寝タイム** | 大人は温泉・ラウンジでリラックス |
| **16:30** | 🌊 ホテル周辺を散歩 | 海の景色を眺めながらゆったり |
| **17:30** | 🏨 **ホテル帰還** ✅ | ← 時間制約クリア |
| **18:00** | 🍽️ ホテル夕食 | 海鮮バイキング or 個室懐石 |

> 💡 **POINT**
> 鳥羽水族館は日本で唯一ジュゴンを飼育。
> 2歳半の子供はラッコ・イルカ・アシカショーで大喜び間違いなし。
> GW中は9:00〜10:00着でも入場待ちが出るため、オンライン購入＆早着が重要。

# 🗓️ 2日目｜伊勢神宮 → おかげ横丁 → 夫婦岩

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  日本の心・伊勢へ。朝の清々しい参拝と食べ歩き
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

| 時間 | 場所・行動 | メモ |
|:---:|---|---|
| **07:00** | 🚗 ホテル出発（早朝移動で混雑回避） | |
| **07:30** | 🐸 **夫婦岩（二見興玉神社）** | カエルの置物に子供が喜ぶ。朝の海が静かで美しい |
| **08:00** | 🚗 伊勢神宮（内宮）へ移動（約20分） | |
| **08:30** | ⛩️ **伊勢神宮（内宮）参拝** | 朝の境内は空気が澄んでいて最高。だっこ紐＋ベビーカー併用 |
| **10:30** | 🍡 **おかげ横丁・おはらい町** 食べ歩き | 伊勢うどん・赤福・海老フライを食べながら散策 |
| **12:00** | 🦐 昼食：おはらい町の海鮮食堂 | てこね寿司・伊勢海老汁セット |
| **12:45** | 🚗 ホテルへ帰還（約25分） | |
| **13:15** | 🏨 ホテル到着 | |
| **13:30** | 💤 **子供 昼寝タイム** | 大人は温泉・読書でリフレッシュ |
| **15:00** | 🛁 家族で大浴場・プール | |
| **17:00** | 🌅 ホテルのテラスで海を眺める | |
| **17:30** | 🏨 **ホテル帰還** ✅ | ← 時間制約クリア |
| **18:00** | 🍽️ ホテル夕食 | 2日目は贅沢に伊勢海老料理を |

> 💡 **POINT**
> 伊勢神宮は **朝8時台の参拝** が最も空いていて清々しい。
> おかげ横丁のベビーカーは混雑時に押しにくいため、だっこ紐も必ず持参。

```

  最終日は内陸の絶景スポットへ。安全な高地で締めくくり
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

| 時間 | 場所・行動 | メモ |
|:---:|---|---|
| **08:00** | 🍳 ホテル朝食・荷造り・チェックアウト | |
| **09:00** | 🚗 御在所ロープウェイへ出発（約1時間） | |
| **10:00** | 🚡 **御在所ロープウェイ** 乗車 | 2歳児がロープウェイに大喜び。大人は山頂からの絶景 |
| **11:30** | 🍱 山頂 or 麓で昼食 | |
| **12:30** | 🚗 帰路へ出発 | 渋滞情報を確認し余裕を持って |
| **〜17:30** | 🏠 **自宅着** ✅ | ← 時間制約クリア |

> 💡 **POINT**
> 御在所ロープウェイは内陸の山岳エリア（標高1,212m）のため、
> 津波リスクがゼロ。最終日を安全な場所で締めくくれる。
> 子供が「ぷかぷかした！」と喜ぶロープウェイ体験が思い出に残る。
