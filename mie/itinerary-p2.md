## 旅のプロフィール

| | |
|---|---|
| 👨‍👩‍👧 **メンバー** | 大人 2名（30代）／ 子供 1名（2歳半） |
| 📅 **期間** | GW2026 ・ 2泊3日 |
| 🚗 **移動** | マイカー |
| 🏨 **宿泊** | ホテルナガシマ（ナガシマリゾート内） |
| 🎯 **テーマ** | 子供が2日間ひたすら遊べる環境に全振り |
| 🌊 **津波安全性** | ⚠️ 低地立地のため上層階確保＋避難計画の事前確認が必須 |

---

> ### ✅ このプランがおすすめな方
> - とにかく子供を遊ばせることを最優先にしたい
> - ホテルと遊び場が直結している利便性を重視したい
> - 大人も一緒に乗り物を楽しみたい
> - 3日目に少し観光（伊勢）も加えたい

---

> ### ⚠️ 津波リスクについて（必読）
> ナガシマリゾートは伊勢湾岸の低地（標高 約2〜5m）に位置します。
> 南海トラフ地震の発生時には、伊勢湾が津波エネルギーを一定量減衰させますが、
> 10m想定に対して低地部分は安全とは言えません。
> **宿泊前にホテルの津波垂直避難計画を確認し、高層階の客室を予約してください。**

# 🗓️ 1日目｜到着 → スパーランド幼児ゾーン → プール

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  到着してすぐ遊べる！ホテルと遊園地が一体の快適さ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

| 時間 | 場所・行動 | メモ |
|:---:|---|---|
| **07:00** | 🏠 自宅出発 | 東名阪・湾岸道経由 |
| **09:30** | 🅿️ ナガシマリゾート到着・駐車 | GW中は早着が必須（駐車場も混む） |
| **10:00** | 🎠 **ナガシマスパーランド「わくわくパーク」入場** | 幼児専用ゾーンのメリーゴーランド・コーヒーカップ等 |
| **11:30** | 🎡 パークを一通り周回 | 子供のペースで乗れるものを全制覇 |
| **12:00** | 🍜 昼食：パーク内フードエリア | 子供向けメニューあり。混雑するので早めに |
| **13:00** | 🏨 チェックイン（ホテルまで徒歩数分） | 荷物を部屋へ |
| **13:30** | 💤 **子供 昼寝タイム** | 大人は部屋でゆったり or スパ利用 |
| **15:00** | 🏊 **ホテル内プール or 温泉** | 幼児エリアを事前確認 |
| **17:00** | 🏨 **部屋に戻る** ✅ | ← 時間制約クリア |
| **18:00** | 🍽️ ホテル夕食 | バイキング形式で子供も食べやすい |

> 💡 **POINT**
> 「わくわくパーク」は2〜5歳向けの幼児専用エリア。
> 大人が付き添えば2歳半でも多くの乗り物を楽しめる。
> GWは激混みのため、**開園と同時に入場**してわくわくパークへ直行が正解。
