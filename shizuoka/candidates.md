# 静岡県（浜松メイン）旅行候補リスト

> 対象：大人2名（30代）＋子供1名（2歳半） | GW2026 | マイカー移動
> 特記：浜松エリアを子供向けメインで検討

---

## 🏨 宿泊候補

### 1. 浜名湖ロイヤルホテル（浜松市・舘山寺温泉）

**判断理由**
浜名湖の舘山寺エリアに位置する温泉ホテル。浜名湖は海ではなく汽水湖（海との接続は浜名湖今切口のみ）のため、周辺エリアは太平洋に直接面しておらず、津波エネルギーが減衰しやすい。舘山寺エリアは丘陵地形で10m以上の標高を持つ部分がある。

| | 内容 |
|---|---|
| 低めの寝具 | △ 洋室ベッド中心。和室プランを選べばお布団対応可能 |
| 子供アメニティ | ◯ キッズアメニティ対応あり（要予約時確認） |
| 子供施設 | ◯ キッズルーム・浜名湖ビューのプールあり |
| 津波リスク | ◯ 浜名湖沿岸は湖が緩衝。舘山寺エリアの高台部分（標高10〜20m）はリスク低。具体的な棟の標高は事前確認推奨 |

**メリット**
- 浜名湖の景観が美しく大人の満足度が高い
- フラワーパーク・動物園へ車で10〜15分
- 温泉でリフレッシュ可能
- 湖側のため波による津波リスクが低め

**デメリット**
- 人気ホテルのためGW予約がすぐ埋まる（早期予約必須）
- 海鮮は外食か近隣で別途手配が必要

---

### 2. ホテルクラウンパレス浜松（浜松市中心部）

**判断理由**
浜松市中心部（駅近）に位置する中高層ホテル。海岸から約5〜6kmの距離があり、市街地が緩衝となる。子供連れでのファミリー利用に定評あり。

| | 内容 |
|---|---|
| 低めの寝具 | △ 洋室ベッド中心。ファミリールームは大型ベッドあり |
| 子供アメニティ | ◯ キッズアメニティ対応あり |
| 子供施設 | ◯ キッズコーナーあり |
| 津波リスク | ◯ 海岸から離れた市街地（標高 約5〜10m）。建物5階以上は10m超え。ただし市街地を津波が浸水するケースも想定されるため、ハザードマップ確認を推奨 |

**メリット**
- 浜松市中心部のため食事・買い物に便利
- 浜名湖・フラワーパーク・動物園へのアクセス良好
- ホテル設備のレベルが高い

**デメリット**
- 海岸線から5kmでも浜松の津波浸水想定区域に含まれる可能性があるため、ハザードマップで正確な浸水深を確認
- 周辺の自然体験は少ない

---

### 3. KKR浜名湖（浜松市・舘山寺）※国家公務員宿泊施設・一般利用可

**判断理由**
浜名湖に面した中規模施設で丘の上に位置。一般客も利用可能で比較的リーズナブル。舘山寺エリアの高台。

| | 内容 |
|---|---|
| 低めの寝具 | ◎ 和室プラン（布団）あり |
| 子供アメニティ | △ 基本的なアメニティのみ（要確認） |
| 子供施設 | △ 施設内の子供向けは限定的 |
| 津波リスク | ◯ 高台立地（舘山寺の丘：標高10〜20m） |

**メリット**
- 和室布団対応で2歳児の就寝環境に最適
- 比較的リーズナブル
- 高台で津波リスク低め

**デメリット**
- 子供向け施設・アメニティが限定的
- GW期間は混雑・予約困難な場合あり

---

### 4. 掛川グランドホテル（掛川市）

**判断理由**
掛川市は浜松と静岡市の間に位置し、海岸線から約5〜7km内陸に立地。掛川花鳥園・掛川城への観光基点として優秀。

| | 内容 |
|---|---|
| 低めの寝具 | △ 洋室中心。和室プランを選択すれば布団対応 |
| 子供アメニティ | ◯ あり（要確認） |
| 子供施設 | △ ホテル内の子供施設は限定的だが、周辺施設が充実 |
| 津波リスク | ◯〜△ 海岸から一定の距離あり。ただし大規模津波では市街地への浸水も想定されるためハザードマップ確認を |

**メリット**
- 掛川花鳥園（子供向け最高評価スポット）まで車5分
- 比較的内陸で津波リスクが相対的に低い

**デメリット**
- 子供向けホテル施設は少なめ
- 浜松中心部より食事の選択肢が減る

## 🎡 子供向け観光・遊び場候補

### 1. はままつフラワーパーク（浜松市）⭐最推奨

**判断理由**
GW期間はチューリップ・バラが最盛期を迎え、日本屈指の美しさ。広い園内をベビーカーで散策でき、2歳半の子供に最適。大人の観光価値も非常に高い。

| 項目 | 内容 |
|---|---|
| 子供向け | ◎ 広い芝生エリア・遊具・カート乗車コーナーあり |
| 滞在時間 | 2〜3時間 |
| 混雑度（GW） | ⚠️ GW最盛期のため混雑必至。開園直後推奨 |
| 海鮮との連動 | △ 近隣に海鮮食堂は少ないが浜名湖うなぎや食事処あり |

**メリット**
- GW期間が花の見頃ピーク（チューリップ・フジ・バラ）
- 広くてベビーカーで回りやすい
- 浜松市動物園と隣接しており、セット券でお得

**デメリット**
- GW中は駐車場が満車になることがある（早朝到着推奨）

---

### 2. 浜松市動物園（浜松市）

**判断理由**
フラワーパークと隣接する動物園。2歳半の子供は動物を見て大喜びできる年齢。ライオン・キリン等の大型動物から身近な動物まで揃う。

| 項目 | 内容 |
|---|---|
| 子供向け | ◎ 2歳児に最適なコンテンツ |
| 滞在時間 | 1〜2時間 |
| 混雑度（GW） | △ フラワーパークほどの混雑ではない |
| セット割引 | ◎ フラワーパークとの共通券あり |

**メリット**
- フラワーパークと同日に訪問可能（隣接）
- 子供の反応が確実に良い施設

**デメリット**
- なし

---

### 3. 掛川花鳥園（掛川市）⭐子供向け最高評価

**判断理由**
温室の中で花と鳥が共存する日本唯一のテーマパーク。ペンギン・オオハシ・フクロウ等に手で餌やりができる。2歳半の子供が実際に動物と触れ合えるため感動体験を得やすい。

| 項目 | 内容 |
|---|---|
| 子供向け | ◎ 触れ合い体験が2歳でも可能 |
| 滞在時間 | 2〜3時間 |
| 混雑度（GW） | △ フラワーパークより空いている |
| 雨天 | ◎ 温室内のため雨天でも完全に楽しめる |

**メリット**
- 雨天対応の屋内施設
- 動物の触れ合い体験が2歳児の記憶・感動に残る
- 大人も非日常体験で十分楽しめる

**デメリット**
- 浜松市街からは車で約30〜40分

---

### 4. 浜名湖ガーデンパーク（浜松市）

**判断理由**
2004年の浜名湖花博跡地を整備した無料の大型公園。GW中は花々が美しく、子供が走り回れる広大な芝生がある。無料で入れるのが魅力。

| 項目 | 内容 |
|---|---|
| 子供向け | ◯ 広い遊具広場・噴水エリアあり |
| 滞在時間 | 1〜2時間 |
| 混雑度（GW） | △ 広大なため分散しやすい |
| 入場料 | ◎ 無料 |

**メリット**
- 無料で広大な空間を楽しめる
- 子供が自由に走り回れる
- 浜名湖の景色が美しい

**デメリット**
- 屋内施設が少なく雨天時は楽しみにくい

---

### 5. 舘山寺ロープウェイ（浜松市・浜名湖）

**判断理由**
浜名湖上空をロープウェイで渡り、山頂から浜名湖を一望できる。乗り物好きな2歳児には非日常体験。所要時間が短いため時間調整にも使える。

| 項目 | 内容 |
|---|---|
| 子供向け | ◯ ロープウェイ自体を楽しめる |
| 滞在時間 | 30〜60分 |
| 混雑度（GW） | △ ある程度混雑するが回転は速い |

**メリット**
- 短時間で楽しめるため他の観光とセットにしやすい
- 子供がロープウェイを喜ぶ
- 山頂からの浜名湖ビューが美しい

**デメリット**
- なし

浜名湖を船で遊覧するアクティビティ。船に乗る体験が2歳児に楽しい。大人は湖の景色を楽しめる。

| 項目 | 内容 |

## 🍣 食事候補

### 1. 浜名湖うなぎ（浜松市・舘山寺エリア）⭐最推奨

**判断理由**
浜松は日本一のうなぎ産地。蒲焼・白焼き・うなぎ丼が楽しめる。2歳児も細かく刻めば食べやすい。海鮮ではないが浜松の食文化を代表するグルメ。

**メリット**
- 浜松に来たら外せない名物
- 子供でも食べやすい

**デメリット**
- 海鮮ではなく淡水魚のため「海鮮メイン」の方針とは若干ズレる

---

### 2. 桜えび・しらす丼（由比〜清水エリア）

**判断理由**
静岡県固有の海鮮グルメ。桜えびは4〜6月が生しらすとともに旬の時期。清水や由比港周辺で新鮮なものが食べられる（浜松からは車で約1時間）。

**メリット**
- GWが旬のタイミングと重なる
- 子供も食べやすい

**デメリット**
- 浜松からは距離があるため別途ドライブが必要
- 天候により漁が休みのこともある（生しらす）

---

### 3. 浜名湖産カキ・アサリ（浜松市）

**判断理由**
浜名湖はカキ・アサリの名産地。GW前後はシーズン終盤になるが、浜名湖産の海鮮を楽しめる料理店がある。

**メリット**
- 浜名湖エリアで完結できる海鮮グルメ
- 子供はアサリの味噌汁など食べやすい

**デメリット**
- GW（5月）はカキシーズン終盤のため、品質・提供状況は要確認

---

### 4. 浜松餃子（浜松市）

**判断理由**
海鮮ではないが浜松の代表的B級グルメ。野菜多めであっさり目の味付けが子供にも食べやすい。夕食の選択肢として便利。

**メリット**
- 子供も食べやすい
- リーズナブルで気軽に食べられる

**デメリット**
- 海鮮ではない

---

### 5. マリンアクア浜名湖・舘山寺周辺 海鮮食堂

**判断理由**
舘山寺温泉エリアには浜名湖の新鮮な魚介を使った食堂がある。宿泊ホテル近辺で海鮮が食べられる。

**メリット**
- 宿泊エリアと同一地域のため移動不要
- ブランドほうじ茶海老・海老天丼など地元食材

**デメリット**
- GW中は満席・予約困難になる場合あり
